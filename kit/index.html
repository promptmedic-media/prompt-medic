Free sample prompt: IDOR hunt

List every API route or server action that takes an id from the request. For each one, say whether it checks that the record belongs to the logged-in user. Then fix only the ones that don't, by adding an ownership check against [SESSION USER FIELD].
Done = every id-based route checks ownership, and the diff touches only those routes.
