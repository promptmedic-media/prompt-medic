Free Prompt Fix Examples: 8 Broken Prompts, Diagnosed and Rewritten

Each example shows a prompt that underperforms, why, and a rewrite. These are illustrative examples in the style of Prompt Medic /fix output.

Vibe coding: vague feature

Before: make the dashboard look better and add dark mode

Diagnosis: "Better" is uncheckable, so the model redesigns everything.

After: Add a dark mode toggle to the dashboard header (React + Tailwind). Use dark: classes, persist in localStorage. Only change colors, not layout. Done = every card and chart switches without reload. Only edit /components/dashboard and tailwind.config.js.

Bug fix with no evidence

Before: my login is broken fix it

Diagnosis: No error, no file, no expected behavior.

After: Login fails with "401 invalid token" after a successful POST /auth/login. Relevant files: auth.ts, middleware.ts. Expected: redirect to /home with a session cookie. Find the root cause, explain it in 2 sentences, then give the minimal diff.

Lovable/Bolt app spec

Before: build me an app like airbnb

Diagnosis: Huge scope, no MVP boundary.

After: Build an MVP listing page for short-term rentals: grid of 12 mock listings (photo, title, price/night, rating), a city search filter, and a detail page. No auth, no payments yet. Use Supabase for listings table with the fields above.

Summaries that ramble

Before: summarize this article

Diagnosis: No length, audience or purpose.

After: Summarize this article in 5 bullets for a busy product manager. Each bullet under 20 words. End with one line: "Why it matters:".

Email that sounds robotic

Before: write an email asking for a refund

Diagnosis: No facts, no tone.

After: Write a polite but firm 120-word email to Acme support requesting a refund for order #4821 (charged twice on Oct 3). Ask for confirmation within 5 business days. No apologies, no exclamation marks.

Code review that is useless

Before: review my code

Diagnosis: No focus, so you get generic advice.

After: Review this Express route for security issues only: injection, auth bypass, secrets in code. List each issue with line number, severity (high/med/low), and a one-line fix. Skip style comments.

Image prompt mush

Before: cool gaming logo

Diagnosis: No subject, style, or constraints.

After: Flat vector logo for a gaming Discord called "Night Shift": a crescent moon wearing a headset, purple and teal, thick outlines, readable at 64px, no text, transparent background.

Agent that loops

Before: research competitors and make a report

Diagnosis: No stopping rule or sources.

After: Find 5 direct competitors to [product] using their official sites. For each: pricing, main feature, target user, one weakness. Output a markdown table. Stop after 5; do not browse more than 10 pages.
