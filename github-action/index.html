Repo Roast GitHub Action

This free, open-source action gives every pull request a 0-10 score plus the security holes AI-written code tends to ship: secrets in NEXT_PUBLIC_ vars, missing ownership checks, Supabase tables with RLS off, and injection. It works with any OpenAI-compatible key (OpenAI, OpenRouter, Groq, local).

View on GitHub See a live demo PR

2-minute setup

Add a repo secret named ROAST_API_KEY, then create .github/workflows/repo-roast.yml:

name: Repo Roast
on: pull_request
permissions:
  contents: read
  pull-requests: write
jobs:
  roast:
    runs-on: ubuntu-latest
    steps:
      - uses: promptmedic-media/repo-roast-action@v1
        with:
          api-key: ${{ secrets.ROAST_API_KEY }}

What the demo PR got

🔴 1/10: "This vibe-coded API is a masterclass in how to leak your entire database." It flagged a service_role key in a NEXT_PUBLIC_ var, an IDOR on /api/orders/:id, an unauthenticated admin delete route, and RLS being bypassed.
