What it does

Four slash commands. The /roast and /patch outputs below are real, and the /fix one is an illustrative example.

/fix: prompt doctor

Paste a prompt that isn't working (and optionally what went wrong). You get a diagnosis, a rewrite, and tips.

Example (illustrative) 
/fix prompt: make the login work
Prompt MedicBOT
🩺 Prompt Medic DiagnosisThe prompt names no stack, no auth method, and no definition of "working", so the model guesses and rewrites unrelated code. Rewritten prompt
Add email/password login to my Next.js app using Supabase Auth. Keep the existing UI and routes. Show validation errors inline under each field. Done = I can sign up, log in, log out, and /dashboard redirects to /login when signed out. Don't modify files outside /app/(auth) and /lib/supabase.
Tips
  • State what "done" looks like
  • Name your stack and the files it may touch
  • One feature per prompt

FAQ

What is Prompt Medic?

A Discord bot for vibe coders and gamers. /fix diagnoses and rewrites AI prompts that are not working, /roast reviews a public GitHub repo or pasted code for security issues and bugs, and /patch summarizes the latest official patch notes for popular games.

Is it free?

Yes. Free users get 3 prompt fixes and 1 repo roast per day, plus public patch-note summaries. Premium is $5/month on Ko-fi for unlimited fixes and roasts, full patch breakdowns, and /mybuild DM alerts.

How do I add it?

Click Add to Discord and pick a server, or add it to your own account so it works in every server and DM. Type /help to see everything it can do.

Which games does the patch digest cover?

Valorant, League of Legends, Apex Legends, Marvel Rivals and Fortnite. Summaries come from official patch notes and developer posts and link back to the source.

Does /roast store or train on my code?

Prompt Medic only reads public repos (README, file tree and up to about 15 key files) or code you paste, sends it to an AI model to generate the review, and does not store your code.

Which AI tools does /fix work for?

Any of them: Cursor, Claude, ChatGPT, Grok, Lovable, Bolt, v0, Copilot, agents and plain chatbots. It fixes the prompt, not the tool.

How do I cancel Premium?

Cancel your membership on Ko-fi anytime. The Premium role is removed when the membership ends.
